## Swisscom SMS v1.1.3

Send failures now reach the caller instead of only being logged.

### Fixed

- A failed SMS no longer looks like a success. Every number in `target` is
  still tried, then the action fails with a single error listing the failed
  numbers and the HTTP status returned by Swisscom.
- An empty `target` now fails the action with a validation error.

### Upgrading

**Behaviour change:** an automation now stops at the SMS step when a message
fails, so the actions after it do not run. To let an automation carry on
regardless, add `continue_on_error: true` to the SMS action.

No stored configuration data changes; no migration runs.

**Full changelog**: https://github.com/Sdavid66/Swisscom-SMS/compare/v1.1.2...v1.1.3
